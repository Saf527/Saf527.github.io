# Safwan Shaikh — Portfolio

Modern futuristic cybersecurity portfolio built with plain HTML, CSS and JavaScript.

## Local setup

1. Open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## GitHub Pages

Recommended repository name:

`Saf527.github.io`

Then:

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/Saf527/Saf527.github.io.git
git push -u origin main
```

In GitHub:
`Repository → Settings → Pages → Deploy from branch → main / root`

Your site should become:

`https://saf527.github.io`

## Before publishing

Replace `assets/Safwan-Shaikh-Resume.pdf` with your actual resume PDF.

The contact form uses FormSubmit to send submissions directly to the configured email address.

GitHub projects are loaded from the public GitHub API for `Saf527`.
